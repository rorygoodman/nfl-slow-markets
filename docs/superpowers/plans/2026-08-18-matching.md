# Matching Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `matching` module — matches a Polymarket NFL moneyline market to one bookmaker's (Paddy Power or Novibet's) equivalent game listing, by team pair + kickoff instant, and looks up a specific team's bookmaker price within a matched game. This is the piece that connects `polymarket_monitor`'s move detection to `paddypower_scraper`'s / `novibet_scraper`'s odds so `arb_finder` (next plan) can compute an edge.

**Architecture:** A bookmaker-agnostic `BookmakerGame`/`BookmakerTeamPrice` pair of dataclasses, with one adapter function per scraper (`from_paddypower`, `from_novibet`) converting each scraper's own `NFLGameOdds` into the common shape — so the core matching logic never has to know which bookmaker it's looking at. Matching itself follows `horsey-scraper`'s established "exact normalized match only, no fuzzy matching" philosophy (a wrong match silently mispricess an alert), adapted from literal name-folding to **team-nickname extraction against a canonical 32-team registry** — necessary because the three data sources name teams completely differently ("Raiders" / "Las Vegas Raiders" / "LV Raiders"), but every source, verified against real live data from all three, always puts the nickname *last*.

**Tech Stack:** Python ≥3.11, `uv`, `pytest`. No new dependencies, no network I/O — this module is pure logic over other modules' already-scraped output.

**Spec:** `docs/superpowers/specs/2026-08-17-nfl-slow-markets-design.md`

## Global Constraints

- Python ≥3.11, managed with `uv`.
- **Exact match only, never fuzzy.** If a team name doesn't fold to a recognized canonical nickname, or a kickoff time doesn't parse, or more than one candidate matches — return `None`. Guessing is worse than missing an alert (mirrors `horsey-scraper`'s `arb_finder/matching.py` design philosophy directly).
- **Polymarket's `question` field has no reliable team-ordering convention.** Verified against live data: for the same real game ("Commanders vs. Lions"), Paddy Power lists it "Washington Commanders @ Detroit Lions" (away @ home) and Novibet lists it "DET Lions vs WAS Commanders" (home vs away) — and Polymarket's own question ordering doesn't consistently match either. **Team matching must always use an unordered pair comparison** (e.g. a 2-element `frozenset`), never positional/index comparison. This directly follows from the exact bug class already found and fixed in `novibet_scraper`'s final review (home-first vs. away-first convention mismatch).
- `matching` calls this project's two scraper modules' own dataclasses (`paddypower_scraper.models.NFLGameOdds`, `novibet_scraper.models.NFLGameOdds`) — read-only, adapts them, never modifies them.
- `match_game(...)` matches against **one bookmaker's game list per call** — the caller (a future `arb_finder`/`orchestrator`) calls it once per bookmaker, matching this project's established "each bookmaker leg handled independently, one's absence doesn't block the other" philosophy.
- Every new top-level package under `src/` added to `pyproject.toml`'s wheel `packages` list in the same task that creates it.
- This plan covers `matching` only. `arb_finder` (the edge calculation) and the `orchestrator` remain out of scope, covered by future plans.

```python
"""Canonical NFL team nickname registry and lookup.

Every team's nickname is a single token, and every data source this
project scrapes always places the nickname last ("Raiders",
"Las Vegas Raiders", "LV Raiders" all end in "Raiders") — verified
against real captured output from Polymarket, Paddy Power, and Novibet.
"""

from __future__ import annotations

import re

CANONICAL_NICKNAMES = frozenset({
    "cardinals", "falcons", "ravens", "bills", "panthers", "bears",
    "bengals", "browns", "cowboys", "broncos", "lions", "packers",
    "texans", "colts", "jaguars", "chiefs", "raiders", "chargers",
    "rams", "dolphins", "vikings", "patriots", "saints", "giants",
    "jets", "eagles", "steelers", "49ers", "seahawks", "buccaneers",
    "titans", "commanders",
})


def _fold(s: str) -> str:
    return re.sub(r"[^a-z0-9]", "", s.lower())


def normalize_team_nickname(name) -> "str | None":
    """Extract the last whitespace-separated token from `name` and
    validate it against the canonical NFL nickname registry. Returns the
    canonical lowercase nickname, or None if `name` isn't a non-empty
    string or its last token isn't a recognized nickname — fails safe
    rather than guessing."""
    if not isinstance(name, str) or not name.strip():
        return None
    last_token = name.strip().split()[-1]
    folded = _fold(last_token)
    return folded if folded in CANONICAL_NICKNAMES else None
```

```python
"""Parse kickoff-time strings from any of this project's three data
sources into a single UTC instant, for cross-source comparison."""

from __future__ import annotations

from datetime import datetime, timezone


def to_instant(value) -> "datetime | None":
    """Accepts Polymarket's "2026-08-22 16:00:00+00" (space separator,
    bare 2-digit UTC offset), Paddy Power's "2026-08-22T16:00:00.000Z",
    or Novibet's "2026-08-22T16:00:00+00:00". Returns a UTC datetime, or
    None if `value` isn't a non-empty string or isn't parseable."""
    if not isinstance(value, str) or not value.strip():
        return None
    try:
        dt = datetime.fromisoformat(value.replace("Z", "+00:00"))
    except ValueError:
        return None
    if dt.tzinfo is None:
        dt = dt.replace(tzinfo=timezone.utc)
    return dt.astimezone(timezone.utc)
```

```python
"""Match a Polymarket NFL moneyline market to one bookmaker's game
listing, by unordered team pair + kickoff instant. Exact match only —
see this plan's Global Constraints for why."""

from __future__ import annotations

import re

from .models import BookmakerGame, BookmakerTeamPrice
from .teams import normalize_team_nickname
from .timeutil import to_instant

_VS_SPLIT = re.compile(r"\s+vs\.?\s+", re.IGNORECASE)


def parse_polymarket_teams(question) -> "tuple[str, str] | None":
    """Extract both team nicknames from a Polymarket moneyline question
    like "Commanders vs. Lions" or "Lions vs Colts". Order is NOT
    meaningful — Polymarket's question field has no reliable home/away
    convention (verified against live data). Returns None if the
    question isn't in the expected two-team shape, or either half isn't
    a recognized NFL nickname."""
    if not isinstance(question, str):
        return None
    parts = _VS_SPLIT.split(question.strip())
    if len(parts) != 2:
        return None
    a = normalize_team_nickname(parts[0])
    b = normalize_team_nickname(parts[1])
    if a is None or b is None:
        return None
    return (a, b)


def match_game(
    polymarket_question: str,
    polymarket_kickoff,
    bookmaker_games: "list[BookmakerGame]",
) -> "BookmakerGame | None":
    """Match against ONE bookmaker's game list per call — callers match
    each bookmaker independently. Matches by unordered team pair +
    kickoff instant. Returns None if the question/kickoff don't parse,
    no game matches, or (never guess) more than one game matches."""
    teams = parse_polymarket_teams(polymarket_question)
    if teams is None:
        return None
    poly_instant = to_instant(polymarket_kickoff)
    if poly_instant is None:
        return None
    poly_pair = frozenset(teams)

    candidates = []
    for game in bookmaker_games:
        game_instant = to_instant(game.kickoff_time)
        if game_instant != poly_instant:
            continue
        n1 = normalize_team_nickname(game.teams[0].team_name)
        n2 = normalize_team_nickname(game.teams[1].team_name)
        if n1 is None or n2 is None:
            continue
        if frozenset((n1, n2)) == poly_pair:
            candidates.append(game)

    return candidates[0] if len(candidates) == 1 else None


def team_price_for(game: BookmakerGame, team_name: str) -> "BookmakerTeamPrice | None":
    """Look up one team's price within an already-matched game, by
    normalized nickname (accepts a bare nickname like "Raiders" or a full
    name like "Las Vegas Raiders" — both normalize the same way). None if
    not found or ambiguous."""
    target = normalize_team_nickname(team_name)
    if target is None:
        return None
    matches = [t for t in game.teams if normalize_team_nickname(t.team_name) == target]
    return matches[0] if len(matches) == 1 else None
```
